# Картинки для сайта

Положи сюда файлы с такими именами — сайт подхватит их сам. Пока файла нет, вместо него показывается заглушка.

| Файл | Где на странице | Размер |
|---|---|---|
| `hero.jpg` | Фон первого экрана (вместо нарисованного заката) | 1920×1080 и больше |
| `city.jpg` | Большая картинка в блоке «О проекте» | 1200×800 |
| `work.jpg` | Карточка «Работа и очередь на автомобиль» | 600×300 |
| `business.jpg` | Карточка «Кооперативы и чёрный рынок» | 600×300 |
| `factions.jpg` | Карточка «Фракции и группировки» | 600×300 |

Лучше всего брать скриншоты с сервера — они честно показывают игру.

# Исходники документов

Все документы в `docs/` собираются из этих скриптов (нужен Node.js и пакет `docx`: `npm install docx`).

| Документ | Команда |
|---|---|
| Устав сервера | `node ustav.js "../Устав Akcent Role Play.docx"` |
| Уголовный кодекс | `node uk.js "../Уголовный кодекс Akcent Role Play.docx"` |
| ПДД | `node pdd.js "../ПДД Akcent Role Play.docx"` |
| Положение об администрации | `node admin.js "../Положение об администрации.docx"` |
| Положение о лидерах | `node leaders.js "../Положение о лидерах.docx"` |
| Устав организации | `node run_charter.js f_ovd "../Уставы организаций/Устав ОВД (милиция).docx"` (и `f_gai`, `f_kgb`, `f_army`, `f_med`, `f_media`, `f_gik`) |

Текст правится в этих файлах, затем документ пересобирается командой из таблицы.
